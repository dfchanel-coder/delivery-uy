# DeliveryUY Product Requirements

## Goal

Create a marketplace allowing local businesses to sell products and receive
delivery orders.

The platform coordinates:

customers
merchants
drivers
payments
delivery

---

# Customer Requirements

Customer can:

register
login
manage profile
manage addresses
detect GPS position
browse merchants
browse products
search
add products to cart
select variants/addons
place order
pay
track order
see driver location
receive delivery code
confirm delivery
see order history
rate order
open support ticket

---

# Merchant Requirements

Merchant can:

register
submit business information
submit documentation
wait for approval
configure business profile
configure hours
manage catalog
manage stock
receive orders
accept/reject orders
mark preparing
mark ready
view history
view financial information
open support requests

---

# Driver Requirements

Driver can:

register
submit personal data
submit vehicle information
submit documents
wait for approval
go online
go offline
receive delivery offers
accept/reject
navigate to merchant
confirm pickup
navigate to customer
submit delivery code
complete delivery
see earnings/history

---

# Admin Requirements

Admin can:

review merchants
review drivers
suspend accounts
review orders
review payments
review refunds
review settlements
review support
configure geographic zones
review audits

---

# Delivery

Delivery requires:

pickup location
destination
assigned driver
order state
live driver location
customer verification code

---

# Realtime

Customer sees delivery progress.

Merchant sees order status changes.

Driver receives delivery assignments.

---

# Scalability

System must support more than one city.

Never hardcode city-specific application logic.
